При отсутствии API, таймауте или ошибке — MP4; ошибка WebM автоматически переключает источник на MP4. Это перекодирование с визуальной проверкой, не математически lossless. Полные показатели SSIM и кадров: optimization-v73/final-metrics.json; сравнительные кадры рядом. Загрузка начинается после загрузчика и только в пределах 320 px от viewport; воспроизведение — при видимости, короткий выход имеет задержку паузы 180 мс. Masonry сначала читает высоты всех карточек, затем пишет только изменившиеся позиции.

## 2026-10-03 — только мягкий боковой наклон, системный запрос (v27)

Расчёт заменён: боковой roll определяется проекцией гравитации в плоскость экрана (матрица W3C Z-X-Y), а не разностью beta/gamma. Он работает при вертикальном положении телефона; направление развёрнуто по замечанию пользователя. Sensor depth всегда 0, gain 0.24, предел ±0.12 rad (около 7°), dead zone 1.5°. Почти плоское положение без устойчивой проекции игнорируется. Проверены вертикальная поза, изменение pitch, направления, ограничения, поворот экрана и null.

Дополнительный UI разрешения удалён. После загрузки вызывается нативный requestPermission; при NotAllowedError без user activation ставится однократный запрос на первое pointerup страницы, а портфолио открывается без блокировки. Отказ не вызывает повторных запросов. Safari требует реальное касание для первого разрешения; обойти это без UI нельзя. 35 тестов проходят. Физическая проверка на iPhone остаётся за пользователем. Источник системы координат: https://www.w3.org/TR/orientation-event/.
