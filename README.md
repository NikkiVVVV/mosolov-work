# mosolov.work

## Портфолио · 2026-10-03

`/test-secret/` — тестовая версия портфолио с WebGL-подвеской, светлой и тёмной темой, карточками проектов и адаптивной мобильной компоновкой. Исходник: `../work/portfolio-prototype/`. Скопированы только исполняемые файлы, используемые ассеты и лицензии; фотографии-референсы и история работы не публикуются. В HTML указан noindex, nofollow. Обновления переносить из исходника, проверять и публиковать через GitHub Pages.

Статические страницы личного сайта. Каталог публикации — `site/`.

- `/` — временный редирект без видимого текста на https://t.me/nikir_public. Удалить при публикации портфолио.
- `/paket/` — «Тот самый пакет»: полная копия готового лендинга от 2026-10-02, включая фотографии, локальные шрифты, карту и WebGL-анимации. Служебный README исходного проекта в сайт не включён.

Для локального просмотра: `python3 -m http.server 4187 --bind 127.0.0.1 --directory site`, затем открыть `http://127.0.0.1:4187/paket/`.

Опубликовано на GitHub Pages: https://github.com/NikkiVVVV/mosolov-work. Каталог `site/` автоматически публикуется через GitHub Actions после push в main. Свой домен `mosolov.work` задан в Settings → Pages; DNS управляется в Porkbun. Корневой ALIAS и CNAME для www направлены на `nikkivvvv.github.io`. Сертификат HTTPS выпускает GitHub.

Лицензии сторонних библиотек и шрифтов сохранены рядом с файлами. Приватные документы, доступы, история чатов и данные регистратора в этот репозиторий не включаются.

Исходная рабочая копия лендинга хранится отдельно в проекте «Фан-пет». Новые изменения не синхронизируются между локальными папками автоматически: сначала обновить `site/paket/`, проверить локально, затем commit и push. GitHub Actions обновляет опубликованный сайт автоматически.

Проверки: `node --test tests/*.test.mjs`; GitHub Actions выполняет их перед публикацией. На iPhone движение включается кнопкой разрешения, одно разрешение используется пакетом, сеткой и открытой карточкой. Системная настройка уменьшения движения отключает эти эффекты.


Движение телефона (2026-10-02): на белом фоне действует абсолютная гравитация — плоско на столе пакет расправляется, вертикально сминается снизу, при боковом наклоне сминается противоположный край. Тень повторяет контур. Фотографии реагируют заметнее: сетка до 7°/9°, открытая карточка до 13°/16°. Проверены 7 автоматических тестов и браузерная модель датчика; физический iPhone пока не проверен. Подробности в CHANGELOG.md.
