## 2026-10-04 — v73: видео VP9/MP4 и стабильная прокрутка

Из исходников подготовлены WebM/VP9 CRF 28 и MP4/H.264 veryslow CRF 20 (Пакет CRF 22), без звука, исходные размеры. У трёх роликов сохранены 24 fps; Пакет восстановлен из исходных декодируемых 298 кадров с шагом 1/30 с, вместо предыдущей нормализации в 24 fps. При отсутствии API, таймауте или ошибке — MP4; ошибка WebM автоматически переключает источник на MP4. Это перекодирование с визуальной проверкой, не математически lossless. Полные показатели SSIM и кадров: optimization-v73/final-metrics.json; сравнительные кадры рядом. SSIM 0.989777–0.998100 относительно оригиналов, синхронизация метрики по номеру кадра исключает округление PTS в WebM.

Загрузка начинается после загрузчика и только в пределах 320 px от viewport; воспроизведение — при видимости, короткий выход имеет задержку паузы 180 мс. Masonry сначала читает высоты всех карточек, затем пишет только изменившиеся позиции.
