## 2026-10-04 — v65: мобильная прокрутка и подвеска

Мобильный WebGL-слой переведён из fixed в абсолютные координаты документа: прокрутка выполняется браузером, без пересчёта камеры по scroll. Размер GPU-буфера меняется только при реальном изменении размеров; высота стабильна при скрытии адресной строки. CSS-размер canvas задан явно, поэтому изменение viewport не растягивает картинку. Desktop и конфигуратор сохраняют fixed-слой; события resize объединяются в кадр. Offscreen margin уменьшен с 600 до 64 px; вне экрана/вкладки цикл останавливается.

Мобильный DPR ограничен 1.25 вместо 1.5, частота видимой подвески — до 60 вместо 30 fps. У верёвки 256 сегментов вместо 384 на мобильном; общие координаты кривой вычисляются один раз на сечение для всех четырёх нитей. Отдельный CPU benchmark на Mac (медиана пяти прогонов по 500 кадров): до 0.375 мс/кадр, после desktop 0.119, mobile 0.087. Это замер расчёта верёвки, не FPS телефона.

Touch: pan-y/pinch-zoom, вертикальный жест остаётся скроллом. Горизонтальный drag начинается после порога 8 px; вертикальная координата захвата фиксирована, удлинение ограничено 0.4. Тап открывает настройки; мышь и вращение в конфигураторе сохранены.

47 тестов проходят. Браузер 390×844: после повторного scroll буфер не меняется (1 выделение), canvas уходит вместе со страницей, stretch=0.000; уход за экран скрывает слой и останавливает цикл, возвращение восстанавливает. Конфигуратор открывается/закрывается. Реальный Chrome на телефоне и нагрев не измерены.
